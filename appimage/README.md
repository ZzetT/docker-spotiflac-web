# SpotiFLAC-Next AppImage Directory

Place your downloaded **SpotiFLAC-Next** Linux AppImage here (e.g., `SpotiFLAC-Next.AppImage`).

> **Note**: SpotiFLAC-Next is a supporter build provided as a thank-you for donating to [SpotiFLAC-Next's development](https://github.com/spotbye/SpotiFLAC-Next) (via [coffee.spotbye.qzz.io](https://coffee.spotbye.qzz.io), Patreon, or other supported donation methods). Due to licensing and author distribution terms, this binary cannot be redistributed within this repository.

Any file ending in `.AppImage` placed in this directory will be automatically detected, prepared, and run by the container.
